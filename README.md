# 🎮 TizenTwitch

A Twitch viewer module for TizenBrew with ad blocking and chat support for Samsung Tizen TVs.

## Features

- 🛑 **Ad Blocker**: Blocks Twitch ads for uninterrupted viewing
- 💬 **Chat Support**: Built-in Twitch chat interface
- 🎨 **Twitch Theme**: Authentic Twitch purple theme
- 📺 **Optimized for TV**: Designed specifically for Samsung TV navigation

## Installation

1. Install TizenBrew from [here](https://github.com/reisxd/TizenBrew)
2. Add `@dskja/tizentwitch` as a NPM module in TizenBrew module manager
3. Navigate to Twitch on your TV
4. The module will automatically load and enhance your Twitch experience

## Building

```bash
cd mods
npm install
npm run build
```

## Development

This module is based on the TizenTube structure and uses:
- Rollup for bundling
- Babel for transpilation
- Core-js for polyfills
- whatwg-fetch for fetch API
